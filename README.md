# Qarat Interior Decorator

Over 20 years of trusted interior contracting and authorized wholesale material supply across Lucknow, Ayodhya, and Uttar Pradesh.

## Features
- **Turnkey Interior Contracting**: Gypsum false ceilings, modular kitchens, drywall partitions, WPC louvers, and UV marble sheet work.
- **Authorized Wholesale Distribution**: Official supply of Saint-Gobain Gyproc, India Gypsum, and USG Knauf materials.
- **Responsive Modern UI**: Built with React 19, Vite, and React Router v7.

## Getting Started

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
